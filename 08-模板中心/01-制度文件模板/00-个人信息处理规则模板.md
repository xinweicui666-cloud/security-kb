```
- 保存期限：劳动关系存续期间及离职后法定保存期限

[根据实际收集字段逐项说明]

- 查阅、复制权
- 更正、补充权
- 删除权
- 撤回同意权

## 4. 联系方式
## 5. 生效日期
```

## 模板3：个人信息保护与数据安全责任条款

适用于员工、地推人员、外包供应商、外包人员的个人信息保护责任约定。

### 基本结构

```
# 个人信息保护与数据安全责任条款

## 一、保密义务
1. 乙方应严格保守在工作中接触到的所有甲方（奇富科技）个人信息和数据
2. 未经甲方书面授权，不得以任何形式向任何第三方披露、提供

## 二、数据安全义务
1. 遵守甲方数据安全管理制度
2. 采取合理必要的安全保护措施
3. 发现安全事件立即报告甲方

## 三、使用限制
1. 仅限为履行工作职责之目的使用甲方数据
2. 不得超出授权范围使用
3. 不得复制、下载、导出非必要数据

## 四、合作终止后的义务
1. 删除或返还所有甲方数据
2. 提供数据销毁证明

## 五、违约责任
1. 违反本条款的，应承担由此给甲方造成的全部损失
2. 甲方有权要求乙方停止违约行为、消除影响、赔偿损失

## 六、保密期限
长期有效，不因合作关系终止而终止

甲方（盖章）：          乙方（签字/盖章）：
日期：                  日期：
```

## 模板4：个人信息保护与数据安全申明与承诺书

适用于外包人员的个人信息保护承诺。

### 基本结构

```
# 个人信息保护与数据安全申明与承诺书

本人（ 姓名 ），身份证号（ ），作为（ 外包供应商 ）派驻至奇富科技的外包人员，已充分了解并承诺遵守以下要求：

1. 严格遵守奇富科技数据安全管理制度
2. 不私自存储、复制、传输、对外提供在工作中接触到的任何数据和信息
3. 不在非授权设备上处理公司数据
4. 不使用个人账号注册或使用公司业务系统
5. 工作终止后，不保留任何公司数据和信息
6. 发现安全事件或隐患，立即上报

如违反以上承诺，本人愿意承担相应的法律责任和赔偿责任。

承诺人（签字）：
日期：
```
