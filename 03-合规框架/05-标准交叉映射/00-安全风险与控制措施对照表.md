# 常见安全风险与控制措施对照表

## 1. 概述

梳理常见安全风险场景对应的威胁分析、风险等级和安全控制措施，为安全评估提供参考。

## 2. 风险对照表

| 风险场景 | 威胁分析 | 风险等级 | 安全控制措施 |
|----------|----------|----------|-------------|
| 弱口令/默认口令 | 攻击者通过暴力破解或默认口令获取系统访问权限 | 高 | 强制复杂密码策略；定期更换密码；首次登录强制修改默认口令 |
| 未授权访问 | 用户通过修改URL或API参数访问超出权限的资源 | 高 | 服务端权限校验；URL访问控制；功能级权限模型 |
| SQL注入 | 攻击者通过恶意构造输入参数执行非授权数据库操作 | 高 | 参数化查询；输入白名单校验；最小数据库权限 |
| XSS跨站脚本 | 攻击者注入恶意脚本，窃取用户信息或会话令牌 | 中 | 输出编码；内容安全策略(CSP)；HttpOnly Cookie |
| 敏感信息泄露 | 系统错误信息或日志中包含敏感数据 | 中 | 统一错误处理页面；日志过滤敏感信息；前端脱敏展示 |
| 密码/密钥硬编码 | 开发人员将密钥、密码写入代码或配置文件上传至仓库 | 高 | 代码扫描检测硬编码；密钥管理系统；Git pre-commit检查 |
| 不安全的文件上传 | 上传恶意文件获取服务器控制权 | 高 | 文件类型白名单；大小限制；病毒扫描；存储目录隔离 |
| 会话劫持 | 攻击者窃取会话令牌冒充合法用户 | 高 | HTTPS传输；令牌随机生成；IP绑定；过期机制 |
| API接口滥用 | 攻击者或恶意用户过量调用API导致服务不可用 | 中 | 速率限制；API认证；请求频率控制 |
| 依赖组件漏洞 | 使用存在已知漏洞的第三方组件或库 | 高 | 软件成分分析（SCA）；定期扫描；依赖版本管控 |
| 日志注入 | 攻击者插入恶意内容污染日志文件 | 低 | 日志输入过滤；格式校验 |
| CSRF跨站请求伪造 | 攻击者诱导用户执行非自愿的操作 | 中 | CSRF Token；Referer检查；SameSite Cookie |
| 信息未加密传输 | 中间人攻击窃取网络传输中的数据 | 高 | 全站HTTPS；TLS1.2+；HSTS配置 |
| 配置错误 | 服务器默认配置暴露敏感信息或提供攻击面 | 中 | 安全基线加固；禁用不必要的服务和端口；定期配置审计 |

## 3. 风险分类统计

| 风险分类 | 数量 | 主要涉及 |
|----------|------|----------|
| Web应用安全 | 5 | SQL注入、XSS、CSRF、文件上传、会话劫持 |
| 访问控制 | 2 | 未授权访问、API接口滥用 |
| 数据保护 | 3 | 敏感信息泄露、信息未加密传输、密码/密钥硬编码 |
| 配置管理 | 2 | 弱口令/默认口令、配置错误 |
| 供应链安全 | 1 | 依赖组件漏洞 |
| 注入攻击 | 1 | 日志注入 |
