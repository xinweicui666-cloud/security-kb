# 适用性声明 (SoA)

## 1. SoA概述
适用性声明(Statement of Applicability, SoA)是ISMS体系的核心文件之一，用于说明组织对ISO/IEC 27001:2022 Annex A和ISO/IEC 27701:2019 Annex A/Annex B中各项控制措施的适用性判断及实施情况。

**SoA的作用：**
- 明确组织选择哪些控制措施以及选择/排除的理由
- 说明每项适用控制措施的实施方式
- 为内外部审核提供控制措施合规性的汇总视图
- 体现组织基于风险评估结果的控制措施选择逻辑

**本SoA覆盖范围：**
- ISO/IEC 27001:2022 Annex A 全部93项控制措施（A.5组织控制37项 + A.6人员控制8项 + A.7物理控制14项 + A.8技术控制34项）
- ISO/IEC 27701:2019 Annex A 隐私信息管理附加控制措施
- ISO/IEC 27701:2019 Annex B 隐私信息管理特定控制措施

## 2. 控制措施适用性判断
对每项控制措施进行适用性判断，判断依据为信息安全风险评估结果和隐私影响评估(PIA)结果。

| 判断结果 | 含义 |
|----------|------|
| 适用 | 该控制措施与组织ISMS范围相关，需要实施 |
| 不适用 | 该控制措施与组织ISMS范围不相关，需说明排除理由 |
| 部分适用 | 该控制措施部分与组织ISMS范围相关 |

**适用性判断原则：**
- 基于风险评估结果：凡风险处置需要该控制措施的，判定为适用
- 基于业务场景分析：与360借条业务（智能风控、智能机器人、反欺诈评估、资质评估、智能营销）相关的控制措施优先判定适用
- 基于法律法规要求：法规强制要求的控制措施必须判定适用
- 基于隐私影响评估：涉及个人数据处理的场景，ISO 27701相关控制措施判定适用

**不适用控制措施的说明要求：**
- 必须记录不适用的理由
- 不得仅以"不涉及"为由排除，需结合风险评估结论
- 管理评审时需重新审视不适用判断的合理性

## 3. 实施方式
每项适用控制措施需说明其具体实施方式，包括：

| 实施要素 | 说明 |
|----------|------|
| 实施方式 | 策略/程序/技术手段/合同条款等 |
| 实施证据 | 对应的文件编号、系统配置、记录表单等 |
| 责任部门 | 负责实施和维护的部门 |
| 实施状态 | 已实施/部分实施/计划实施 |

**实施方式分类：**
- **策略文件**：对应3级策略文件（ISMS-B1~B8），如信息安全策略、访问控制策略等
- **程序文件**：对应2级程序文件（ISMS-C1~C26），如内部审核程序、供应商管理程序等
- **技术措施**：系统配置、安全工具、加密方案等技术实现
- **合同条款**：与外部方签订的合同中包含的安全条款
- **管理措施**：培训、意识教育、监督检查等管理手段

## 4. 控制目标与风险
每项控制措施对应以下要素：

| 要素 | 说明 |
|------|------|
| 控制目标 | 该控制措施要达到的安全目标 |
| 对应风险 | 该控制措施要应对的信息安全风险/隐私风险 |
| 风险处置方式 | 规避/转移/降低/接受 |
| 关联风险评估 | 关联的信息安全风险评估记录编号或PIA报告编号 |

**控制目标示例：**
- A.5.1 信息安全策略：确保管理层定义并批准信息安全策略
- A.5.10 供应商关系：确保与供应商协议中包含信息安全要求
- A.8.2 特权访问权限：确保特权访问权限的分配和使用受到控制
- P.5 个人信息管理：确保个人信息处理活动符合隐私保护要求

## 5. 参考文件
SoA的编制和维护需参考以下文件：

| 文件编号 | 文件名称 | 用途 |
|----------|----------|------|
| ISMS-A1-2020 | 信息安全与隐私管理手册 | ISMS体系范围、方针、目标 |
| ISMS-C1~C26 | 程序文件（26个） | 各控制域的程序要求 |
| ISMS-B1~B8 | 策略文件（8个） | 各控制域的策略要求 |
| - | 信息安全风险评估报告 | 风险评估结果与处置计划 |
| - | 隐私影响评估(PIA)报告 | 隐私风险评估结果 |
| - | 供应商安全评估报告 | 外部方安全评估证据 |
| - | 内部审核报告 | ISMS符合性证据 |
| - | 管理评审报告 | ISMS适宜性证据 |

**SoA维护要求：**
- 每次风险评估后需更新SoA
- 每次管理评审后需审视SoA的适用性判断
- 控制措施变更时需及时更新SoA
- 内外部审核时需验证SoA与实际实施的一致性
