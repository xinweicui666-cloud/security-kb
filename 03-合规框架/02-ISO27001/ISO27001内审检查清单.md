# ISO27001 内审检查清单

## 1. 标准概述
ISO/IEC 27001:2022第9.2条要求组织按计划的时间间隔进行内部审核，以提供ISMS符合以下要求的信息：
- 组织自身对ISMS的要求
- ISO/IEC 27001:2022的要求
- 组织确定的ISMS范围

**内审目的：** 确保ISMS持续有效运行和改进，验证ISMS的符合性、有效性和适宜性。

**内审频次：** 每年不少于一次，两次内审间隔不大于12个月。

## 2. 控制域与要求
### 2.1 内审流程
| 步骤 | 内容 | 责任人 |
|------|------|--------|
| 1. 制订内审方案 | 确定内审范围、频次、方法、资源 | 管理者代表 |
| 2. 制订内审计划 | 确定审核日程、审核组分工、审核条款 | 内审组长 |
| 3. 首次会议 | 说明审核目的、范围、方法、日程安排 | 内审组长 |
| 4. 执行内审 | 按检查清单逐项审核，收集审核证据 | 内审员 |
| 5. 信息整理 | 汇总审核发现，判定符合性 | 内审员 |
| 6. 报告结果 | 编制内审报告，提出不符合项 | 内审组长 |
| 7. 跟踪验证 | 验证不符合项纠正措施的有效性 | 内审组长 |

### 2.2 内审员要求
- 具备内审员资质（经过培训并考核合格）
- 保持公平公正，独立于受审核活动
- 不得审核本部门工作（确保审核独立性）
- 具备信息安全管理和隐私管理相关知识

### 2.3 不符合项分类
| 类别 | 定义 | 处理要求 |
|------|------|----------|
| 严重不符合项 | ISMS体系存在系统性失效或区域性失效，导致体系运行严重偏离标准要求 | 必须制定纠正措施，限期整改 |
| 一般不符合项 | 偶发性或孤立性的不符合，不影响体系整体运行 | 制定纠正措施，下次内审验证 |
| 观察项 | 潜在的不符合趋势或可改进的机会 | 记录并关注，非强制整改 |

## 5. 评估方法
- **文件审核**：审查ISMS文件的完整性、适宜性和符合性
- **现场审核**：通过面谈、观察、抽样检查验证实际执行情况
- **记录审查**：检查各类记录表单的完整性和时效性
- **跟踪验证**：对不符合项的纠正措施进行跟踪验证，确认整改有效

**内审方案要求：**
- 考虑以往审核结果，对问题较多领域增加审核频次
- 考虑ISMS过程的重要性和相关风险
- 确保审核覆盖ISMS范围内的所有过程和区域

## 6. 常见不符合项
| 不符合项 | 对应条款 | 整改建议 |
|----------|----------|----------|
| 风险评估未覆盖全部业务场景 | 6.1 | 扩大风险评估范围，补充PIA评估 |
| 安全培训记录不完整 | A.6.3-6.5 | 建立培训台账，确保全员覆盖 |
| 供应商安全评估未覆盖全部合作方 | A.5.10-5.12 | 完善供应商清单，逐一评估 |
| 部分系统变更管理流程未严格遵循 | A.8.32 | 加强变更流程管控，完善审计日志 |
| 隐私影响评估未覆盖全部涉及个人数据的业务场景 | P.5 | 补量所有个人数据处理活动，补充PIA |
| SoA与实际实施不一致 | 6.1.3d | 更新SoA，确保与实际控制措施一致 |
| 内审不符合项整改未闭环 | 9.2 | 建立整改跟踪机制，确保验证闭环 |
