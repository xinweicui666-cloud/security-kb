# ISO27001 合规要求

## 1. 标准概述
ISO/IEC 27001是国际信息安全管理体系标准，规定了建立、实施、维护和持续改进信息安全管理体系（ISMS）的要求。

**当前认证状态：**
- **已获得ISO27001信息安全管理体系认证**
- **已获得ISO27701隐私安全管理体系认证**

ISO27701是ISO27001的隐私扩展，为保护个人隐私提供了额外的控制要求。

### ISMS体系范围
- **业务范围**：对支撑360借条业务的智能风控、智能机器人、反欺诈评估、资质评估、智能营销金融科技产品业务服务的信息安全与隐私管理
- **物理范围**：北京360总部、上海星创科技广场、上海陆家嘴金融服务广场、深圳京地大厦
- **适用人员**：全体员工
- **管理负责人**：信息安全管理负责人/隐私合规负责人——吴业超

### PDCA持续改进模型
| 阶段 | 内容 |
|------|------|
| Plan（规划） | 建立ISMS范围、方针、目标、风险评估与处置 |
| Do（建立与实施运行） | 实施运行ISMS，执行风险评估处置、控制措施、培训与意识 |
| Check（监视与评审） | 执行监视测量、内部审核（每年）、管理评审（每年）、信息安全绩效评价 |
| Act（保持与改进） | 采取纠正措施、预防措施，持续改进ISMS |

### 四层文件体系
| 层级 | 类型 | 文件示例 |
|------|------|----------|
| 1级 | 管理文件 | ISMS-A1管理手册、ISMS-A2适用性声明(SoA) |
| 2级 | 程序文件 | 26个程序文件（ISMS-C1~C26） |
| 3级 | 策略文件 | 8个策略文件（ISMS-B1~B8） |
| 4级 | 记录文件 | 各类记录表单和报告 |

### 风险评估与绩效评价
- **信息安全风险评估**：识别、分析、评价信息安全风险，确定风险处置计划
- **隐私影响评估(PIA)**：对涉及个人数据处理的活动进行隐私影响评估
- **内部审核**：每年不少于一次，间隔不大于12个月
- **管理评审**：每年进行一次，评审ISMS的适宜性、充分性和有效性

## 6. 常见不符合项
- 部分供应商安全评估未覆盖全部合作方
- 安全培训记录不完整
- 部分系统变更管理流程未严格遵循
- 隐私影响评估未覆盖全部涉及个人数据的业务场景
