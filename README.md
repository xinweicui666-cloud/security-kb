# 安全合规知识库

> 让组织里的安全与合规知识可查询、可复用、可沉淀。

## 知识库结构

```
安全合规知识库/
├── 01-制度体系/          # 安全管理制度文件
├── 02-技术基线/          # 各类安全技术基线与配置规范
├── 03-合规框架/          # 等保2.0 / ISO 27001 / SOC 2 / GDPR 合规映射
├── 04-审计与整改/        # 审计记录、不符合项跟踪、整改管理
├── 05-风险案例/          # 行业安全事件、内部风险事件、风险复盘
├── 06-应急响应/          # 应急预案、响应流程、演练与复盘
├── 07-FAQ/               # 安全合规常见问题解答
└── 08-模板中心/          # 各类安全合规文档模板
```

## 模块说明

### 01-制度体系

组织安全管理制度的顶层文件，包括信息安全管理总纲、访问控制、数据安全、密码应用、变更管理、供应商安全、人员安全、安全培训等制度。

### 02-技术基线

各技术领域的安全配置基线，包括主机安全（Linux/Windows）、云平台安全（阿里云/AWS/K8s）、数据安全（分类分级/加密脱敏/留存销毁）、开发安全（代码扫描/依赖管理/CI-CD）、网络安全（分区隔离/防火墙/VPN）。

每个基线文件包含：配置要求 → 风险说明 → 检查方法 → 修复方法 → 合规映射。

### 03-合规框架

覆盖四大合规标准的要求映射与评估工具：

| 标准 | 核心文件 |
|------|----------|
| 等保2.0 | 要求映射表、定级指南、测评检查清单 |
| ISO 27001 | 控制措施映射表、适用性声明(SoA)、内审检查清单 |
| SOC 2 | 信任服务标准映射、控制矩阵、readiness评估清单 |
| GDPR | 合规要求映射、数据处理活动记录(ROPA)、DPIA评估模板 |
| 交叉映射 | 多标准控制项对照表 |

### 04-审计与整改

审计全流程管理，涵盖内部/外部审计记录、不符合项跟踪、整改计划与验证、审计报告。

### 05-风险案例

安全事件的沉淀与学习，包括行业典型事件（数据泄露/勒索软件/供应链攻击）、内部风险事件记录、风险复盘报告。

### 06-应急响应

应急响应体系，包括各类应急预案（数据泄露/勒索/DDoS/供应链）、响应流程与SLA、事件分级标准、演练记录、事后复盘。

### 07-FAQ

按主题分类的常见问题速查：安全制度、数据安全、合规要求、权限与访问、应急响应。

### 08-模板中心

标准化文档模板，包括制度文件模板、评估模板（风险评估/供应商评估/DPIA）、检查清单（上线/变更/日常巡检）、报告模板（月报/季报/年度报告）。

## 使用指南

1. **查询知识**：按模块导航至目标文件，根据章节标题快速定位内容
2. **引用制度**：制度文件编号可跨模块引用，保持一致性
3. **合规映射**：通过 `03-合规框架/05-标准交叉映射/多标准控制项对照表.md` 查找不同标准间的对应关系
4. **模板使用**：从 `08-模板中心` 获取标准模板，按需填写后归档至对应模块

## 文件规范

- 文件格式：Markdown（.md）
- 编码：UTF-8
- 命名规则：序号-中文名称.md
- 内容结构：已填充文件顶部标注 `> 来源：xxx` 说明来源制度
- 版本管理：通过 Git 追踪变更历史
