# 应用安全基线

## 1. 概述

应用安全基线定义了公司所有业务系统和APP必须满足的最低安全设计要求，覆盖应用开发生命周期的各个阶段。

## 2. 通用安全设计要求

### 2.1 身份认证

| 要求 | 检查项 | 风险等级 |
|------|--------|----------|
| 统一认证 | 业务系统原则上统一使用安全认证中心进行认证和登录 | 高 |
| 密码复杂度 | 15位以上，大小写字母+数字+特殊符号至少满足三项 | 高 |
| 密码有效期 | 不超过180天 | 中 |
| 防暴力破解 | 登录失败锁定机制，连续失败5次锁定30分钟 | 高 |
| 会话管理 | 会话超时自动退出，超时时间不超过30分钟 | 中 |

### 2.2 权限控制

| 要求 | 检查项 | 风险等级 |
|------|--------|----------|
| 最小权限 | 用户得到的权限为其工作所需的最小权限范围 | 高 |
| 敏感权限管控 | 敏感权限（四要素信息、OPS权限等）需严格管控和复核 | 高 |
| 管理员限制 | 严格限制管理员帐户数目 | 中 |
| 越权防护 | 系统需辨识用户权限，禁止访问非授权内容 | 高 |
| 临时权限 | 临时分配的帐号在使用完毕后需尽快禁用或删除 | 中 |

### 2.3 日志审计

| 要求 | 检查项 | 风险等级 |
|------|--------|----------|
| 日志记录 | 记录用户登录信息、操作行为、系统事件 | 高 |
| 保留期限 | 日志留存至少6个月 | 高 |
| 日志保护 | 严格控制日志访问权限，重要日志主备存储和加密 | 中 |
| 敏感操作 | 敏感信息查询/下载操作需详细记录 | 高 |

### 2.4 数据安全

| 要求 | 检查项 | 风险等级 |
|------|--------|----------|
| 数据脱敏 | 系统前端页面中对敏感字段脱敏显示 | 高 |
| 加密存储 | L3级及以上数据加密存储 | 高 |
| 密码保护 | 配置文件和代码中禁止明文存储密码、密钥、Token | 高 |
| 禁止批量下载 | 禁止用户在前端批量导出敏感数据 | 高 |
| 数据删除 | 用户数据在超过存储期限后进行去标识化处理 | 中 |

### 2.5 配置安全

| 要求 | 检查项 | 风险等级 |
|------|--------|----------|
| 默认配置 | 遵循CIS Benchmarks强化操作系统、中间件、数据库配置 | 中 |
| 端口服务 | 禁用不必要的服务、端口和默认账户 | 中 |
| 错误处理 | 禁用服务器目录列表、错误回显（数据库报错、堆栈信息） | 中 |
| 变更管理 | 所有配置变更需通过统一工单审批，禁止直接修改生产环境 | 高 |

## 3. 安全测试要求

- 业务系统、APP上线前需通知信息安全部进行安全检测
- 所有部署在线的服务接口都需接受信息安全部的安全扫描
- 禁止屏蔽信息安全部的安全扫描行为
- 不允许以任何形式将客户敏感信息泄露到外部系统或公共资源上
