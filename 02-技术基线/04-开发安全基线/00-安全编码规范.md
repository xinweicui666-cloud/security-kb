# 安全编码规范

## 1. 概述

规范应用系统开发过程中的安全编码要求，防范常见安全漏洞，确保代码质量和应用安全。

## 2. 输入验证

| 要求 | 说明 | 风险等级 |
|------|------|----------|
| 输入校验 | 对人工或通过各类采集程序输入系统的数据进行校验 | 高 |
| 类型检查 | 仅限已定义类型、格式和长度的数据输入系统 | 高 |
| 参数化查询 | 数据库操作应采用参数化查询，防范SQL注入 | 高 |
| XSS防护 | 对用户输入内容进行编码/转义，防范跨站脚本攻击 | 高 |
| 文件上传 | 上传文件需校验类型、大小，限制上传目录权限 | 高 |

## 3. 认证与会话管理

| 要求 | 说明 | 风险等级 |
|------|------|----------|
| 统一认证 | 系统原则上使用奇富安全认证中心统一认证 | 高 |
| 会话保护 | 会话令牌应随机生成，使用HTTPS传输 | 高 |
| 超时退出 | 会话超时不超过30分钟，用户退出后令牌立即失效 | 中 |
| 防暴力破解 | 登录失败锁定，锁定阈值和时长合理设置 | 高 |

## 4. 访问控制

| 要求 | 说明 | 风险等级 |
|------|------|----------|
| 最小权限 | 权限设计满足最小必要原则 | 高 |
| 权限验证 | 服务端进行权限验证，不依赖前端校验 | 高 |
| 强制鉴权 | 所有接口调用必须经过鉴权，禁止未经认证的访问 | 高 |
| URL防护 | 禁止通过修改URL参数访问未授权资源 | 高 |

## 5. 密码与密钥管理

| 要求 | 说明 | 风险等级 |
|------|------|----------|
| 禁止硬编码 | 禁止在代码、配置文件、环境变量中明文存储密钥、密码、Token | 高 |
| 安全存储 | 密码使用安全哈希算法（bcrypt/scrypt）加盐存储 | 高 |
| 密钥管理 | API Key、AK/SK等使用集中式密钥管理系统 | 高 |
| 环境隔离 | 开发、测试、生产环境使用不同的密钥和配置 | 中 |

## 6. 日志与错误处理

| 要求 | 说明 | 风险等级 |
|------|------|----------|
| 敏感信息隐藏 | 错误信息不应泄露系统内部结构、数据库信息等 | 中 |
| 操作日志 | 记录关键操作（登录、权限变更、敏感数据访问等） | 高 |
| 日志保护 | 日志信息不被未授权访问、修改或删除 | 中 |

## 7. 数据保护

| 要求 | 说明 | 风险等级 |
|------|------|----------|
| 传输加密 | 敏感数据通过HTTPS/TLS1.2+传输 | 高 |
| 存储加密 | L3及以上级别数据加密存储 | 高 |
| 数据脱敏 | 前端展示时对敏感字段（手机号、身份证号等）脱敏处理 | 高 |
| 数据删除 | 提供安全的数据删除功能，确保数据不可恢复 | 中 |

## 8. 禁止行为

- 🚫 禁止使用已知存在漏洞的组件和库版本
- 🚫 禁止在生产环境中启用调试模式和测试接口
- 🚫 禁止上传包含密钥、密码、Token的代码到代码仓库
- 🚫 禁止在代码注释中包含敏感信息
- 🚫 禁止使用弱加密算法（MD5、SHA1、DES等）
