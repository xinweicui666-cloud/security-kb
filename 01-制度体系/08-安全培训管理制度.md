# 安全培训管理制度

## 1. 目的

为了保障数据主体合法权益及公司数据利益，指导员工合规使用个人信息及数据，规范公司数据安全培训及考评流程。

**制定依据：**
- 《中华人民共和国网络安全法》《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》《中华人民共和国劳动法》
- 《360数科个人信息保护与数据治理基本政策》《360数科数据安全管理制度》《360数科数据分类分级管理制度》《360数科信息安全员工管理手册》

## 2. 适用范围

- 公司全体员工
- 特别是从事个人信息及数据处理岗位上的相关人员
- 接触或操作公司敏感数据（L2级数据及以上）的人员

## 3. 职责分工

| 角色 | 职责 |
|------|------|
| 数据安全风险专项小组 | 负责组织员工开展安全意识教育培训和安全操作技能培训 |
| 各部门 | 根据实际业务需要进一步加强和落实数据安全培训工作，积极配合培训安排 |

## 4. 管理要求

### 4.1 培训安排

数据安全风险专项小组对数据安全主要技术及管理岗位人员**每年开展不少于20个小时**的数据安全教育培训和技能培训，培训内容包括但不限于：

- 数据安全法律法规
- 制度要求
- 技术规范

### 4.2 培训触发场景

应当组织数据安全培训的情形包括：

| 序号 | 场景 |
|------|------|
| 1 | 数据安全领域有重大影响的法律、法规发布后 |
| 2 | 公司数据安全管理制度发生重大变更时 |
| 3 | 公司隐私政策等文件发生重大变化时 |
| 4 | 定期（不少于每年一次）组织全员数据安全意识培训 |
| 5 | 定期（不少于每年一次）组织相关部门进行应急响应培训和应急演练 |
| 6 | 相关部门根据业务需求申请组织培训的 |
| 7 | 公司发生个人信息安全事件后 |
| 8 | 其他经工作小组评估认为需要开展培训的情况 |

### 4.3 培训方式

数据安全培训可以采取以下多种方式：
- 线上课程学习
- 线下培训
- 下发资料自主学习

### 4.4 培训考核

工作小组结合培训内容及培训重要程度，视情况安排培训考核：

- **全员培训考核：** 视培训内容重要程度合理安排，包括培训中安排答题环节、培训后安排线上考试环节
- **专项培训考核：** 敏感权限人群的培训应按照要求完成培训考核，工作小组有权根据培训参与程度、考核结果对敏感权限进行管理（包括权限开通、关闭）

### 4.5 培训记录

- 公司应形成安全教育和培训记录，包含：培训人员、培训内容、考核结果
- 培训记录由培训组织部门留档备案
- **培训记录保留时间不低于3年**
- 所有培训应要求受训人员考勤签到，签到记录保留不低于3年

## 5. 考核要求与奖惩规范

### 5.1 奖惩原则

对于员工的考核及惩戒应坚持实事求是、尽职免责、权责统一、宽严适度、教育与惩戒相结合的原则。

### 5.2 考核要求

公司员工数据安全考核应当遵守以下要求：

1. 遵守公司规章制度，不得通过任何形式发布违反宪法、法律、侵犯公司或第三人合法权益、泄露用户个人信息的言论或行为
2. 遵守公司个人信息保护及数据安全管理规章制度要求
3. 不得从事非法侵入他人网络、窃取网络数据等危害网络安全的活动
4. 参加公司组织的培训，认真学习
5. 应当根据工作小组的协调和安排，积极执行、配合并监督公司个人信息保护与数据安全治理工作
6. 遵守公司及部门制定的培训考核要求
7. 遵守其他法律、法规及公司制度规定的内容

### 5.3 惩戒细则

- 员工未按要求完成安全培训的，或未通过数据安全培训与考核的，公司有权采取惩戒措施，包括但不限于限制或关闭其操作权限等
- 员工因违反公司数据安全管理制度，造成安全事件、重大经济损失（损失超过人民币5000元）或声誉损失的，公司有权视情形采取通报批评、书面警告、降职降薪、解除劳动合同等措施
- 涉嫌犯罪的，依照相关法律法规规定处理
