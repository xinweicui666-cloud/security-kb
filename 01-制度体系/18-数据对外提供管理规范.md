# 数据对外提供管理规范

## 1. 目的

规范公司数据对外提供的管理流程，明确审批程序和安全要求，确保数据对外提供过程的安全性和合规性。

## 2. 适用范围

适用于奇富科技股份有限公司及附属公司所有数据对外提供场景。

## 3. 定义

**数据对外提供：** 指向公司以外的组织或个人以任何方式（包括但不限于传输、共享、导出、开放API等）提供公司数据的行为。

## 4. 基本原则

- **最小必要原则：** 对外提供数据应限于实现业务目的所必需的最小范围
- **审批先行原则：** 所有数据对外提供必须获得相应审批
- **安全传输原则：** 对外提供数据必须通过安全通道，进行加密保护
- **责任明确原则：** 数据提供方需签署保密协议，明确双方责任

## 5. 管理要求

### 5.1 分级审批

| 数据级别 | 审批要求 |
|----------|----------|
| L4（绝密） | 高层级领导邮件审批 + 业务/合规/安全三方评估 + 签署保密协议 |
| L3（机密） | 邮件/信息安全平台申请 + 部门领导审批 + 信息安全部审批 + 加密提供 |
| L2（秘密） | 部门领导审批 + 信息安全部审批 |
| L1（内部公开） | 信息安全组审核 |

### 5.2 安全要求

- 对外提供前需进行数据安全风险评估
- 涉及个人信息的需取得个人的同意或符合法定情形
- 需与接收方签署保密协议，明确数据保护义务
- 对外传输须采用加密通道和加密方式
- 禁止传输明文数据
- 数据使用完毕后要求接收方及时删除并确认

### 5.3 记录留存

- 对外提供数据的记录（目的、范围、接收方、审批信息）应留存备查
- 记录保存期限不低于5年

## 6. 对外提供机密数据审批流程

1. 业务部门以邮件、信息安全平台、资信平台提出数据提供申请
2. 申请需包含：数据用途、数据范围、数据量级、接收方信息
3. 按照数据级别进行相应审批
4. 与接收方签署《保密协议》
5. 加密提供，不得提供明文数据
6. 保密协议中列明数据保护措施及责任条款
