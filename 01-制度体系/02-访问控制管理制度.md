# 访问控制管理制度

## 1. 目的

规范公司内部系统使用的规范，确保系统的安全性，保护客户敏感信息不受侵犯，降低内部数据泄露风险。

## 2. 适用范围

适用于奇富科技股份有限公司及附属公司。

## 3. 职责分工

| 角色 | 职责 |
|------|------|
| 信息安全部 | 保障制度执行的规范性和有效性，包括合规审计、权限监督等 |
| 系统运维部 | 系统配置管理、权限变更等流程的审批和确认，确保权限合理且最小必要 |
| 业务系统负责人 | 监督用户在业务系统上的操作行为，如发现违规行为按处罚规定处理 |
| 业务系统管理员 | 负责各业务系统的授权管理 |
| 所有用户 | 严格遵守制度中的各项规定，不得进行非授权访问行为 |

## 4. 管理要求

### 4.1 用户管理

#### 4.1.1 用户访问管理
- 公司业务系统原则上统一使用奇富安全认证中心进行认证和登录
- 因客观原因无法加入安全认证中心的系统，需配置账号密码认证策略，经信息安全审批
- 未接入域控的业务系统，由各业务系统负责人定期进行权限复核
- 各业务部门人员仅有权访问职能范围内且已被授权的业务系统
- 若因工作职责需要访问非职能范围内的业务系统，需按流程进行授权审批

#### 4.1.2 用户权限管理
- 申请系统访问权限需通过内部统一权限系统或邮件申请（包括灵犀、信息安全平台）
- 各业务系统负责人不得在没有工单申请的情况下私自授权给用户
- 严格限制管理员帐户数目，没有特殊原因，不得新增或分配用户管理员权限帐户
- 非经审批流程不允许私自添加或者修改用户权限、角色或相关信息
- 临时分配的帐号在使用完毕后需尽快禁用或删除
- 员工因岗位调整、离职等情况不再需要该系统权限时，应及时收回

#### 4.1.3 用户访问权的复查
- 信息安全部定期查看用户帐号及权限分配使用情况
- 常规账号：每年查看一次
- 敏感权限账号：每半年查看一次
- 若发现用户访问行为与访问控制策略不符，按照处罚规定作出相应处罚

### 4.2 敏感权限管理

敏感权限指可查看用户四要素信息、OPS权限、客服系统权限、堡垒机权限等内部业务系统核心权限：
- 严格控制对用户敏感权限的授权，分配操作需做记录并同步信息安全部
- 定期对敏感权限进行复核，确保敏感权限人员账号与实际使用人保持一致
- 及时对已离职人员的敏感权限进行回收
- 信息安全部定期对敏感权限账号进行审计与培训

### 4.3 隐私信息管理

- 系统管理员及开发人员需对系统内的敏感信息进行安全脱敏管理
- 用户申请权限时，原则上无论何种角色，针对于用户敏感信息均不可见
- 具有下载权限的用户，应严格遵守公司相关制度，不得向第三方提供账号权限
- 针对管理员及非管理员权限账户查询/下载敏感信息操作需记入日志，日志需包含操作时间、操作人、操作接口及查询数据内容

### 4.4 用户口令管理

- 用户应对自己的账号口令保密，不得将账号口令泄露给他人
- 用户应第一时间更改分配给自己的账号初始口令
- 口令设置要求：15位以上，大小写字母+数字+特殊符号四项中至少满足三项，不能有名字全拼、不能有连续数字或键位超过三位
- 密码有效期不超过180天
- 如确因系统不可抗力因素无法设置，需向信息安全部报备说明缘由

### 4.5 菜单管理

- 业务系统的菜单应按照各用户所拥有的相应权限进行分配
- 各业务系统菜单中的"系统设置"仅管理员账户可以使用
- 菜单栏应按照业务层面进行逻辑排列，不得将系统菜单和业务菜单混为一体

## 5. 技术要求

### 5.1 配置管理

- 配置文件、环境变量中禁止明文存储密码、密钥、API Token等信息，系统配置信息均需脱敏、加密
- 遵循CIS Benchmarks等安全基线要求，强化操作系统、中间件、数据库的默认配置
- 禁用不必要的服务、端口和默认账户，定期更新默认密码
- 所有配置变更需通过灵犀平台进行统一工单审批，禁止直接修改生产环境
- 禁用服务器目录列表、错误回显（如数据库报错、堆栈信息）
- 定期进行配置文件的合规性检查、审计，修复偏差

### 5.2 日志管理

- 各业务系统应全面记录系统安全事件、用户访问记录、系统运行日志、系统运行状态等
- 日志应记录用户登录信息：账号、登录是否成功、登录时间、登录IP地址
- 日志留存时间6个月及以上
- 严格控制日志访问权限，重要日志采用主备存储和加密等措施

### 5.3 安全测试

- 业务系统、APP上线前需通知信息安全部进行安全检测
- 所有部署在线的服务接口都需接受信息安全部的安全扫描
- 禁止屏蔽信息安全部的安全扫描等行为

## 6. 检查与考核

- 信息安全部定期查看用户帐号及权限分配使用情况
- 若发现用户访问行为与访问控制策略不符，按《奇富科技信息安全员工处罚管理规定》处罚
- 相关惩罚细则参见《奇富科技信息安全员工处罚管理规定》
