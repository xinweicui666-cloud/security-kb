# 信息安全管理总纲

## 1. 目的

为加强本公司数据处理活动中的法律遵从、合规管理及风险控制，保护数据主体合法权益及公司数据利益，制定本政策。本政策是公司个人信息保护、数据安全及合规管理制度、规范、指引的总则，全面规范公司数据处理活动。

## 2. 适用范围

- **地域范围：** 中华人民共和国境内开展的数据处理活动
- **数据范围：** 个人信息及其他纸质形式与电子形式的数据的收集、存储、使用、加工、传输、提供、公开、删除等处理活动
- **人员范围：** 公司所有部门，公司正式员工、项目制员工、实习人员及其他基于法律或协议规定受公司管理的人员

## 3. 基本原则

| 原则 | 说明 |
|------|------|
| 正当原则 | 处理数据应当采用正当的方式，遵循诚信原则，不得通过误导、欺诈、胁迫等方式处理数据 |
| 合法原则 | 不得非法收集、使用、加工、传输数据，不得非法买卖、提供或者公开数据 |
| 最小必要 | 处理数据应当具有明确、合理的目的，限于实现合法处理目的的最小范围 |
| 目的限定 | 按照合同约定的特定目的或其授权同意的范围处理相关数据 |
| 公开透明 | 处理个人信息应当遵循公开、透明的原则，明示个人信息处理规则 |
| 权责一致 | 个人信息处理者对其数据处理活动负责，并采取必要措施保障数据安全 |
| 保证数据质量 | 处理数据应当保证数据的质量，避免因数据不准确对他人合法权益造成不利影响 |

## 4. 安全组织架构

### 4.1 数据安全委员会

公司组建数据安全委员会负责个人信息保护及数据安全管理工作。委员会成立之前，由数据安全风险专项小组代行职责。

**委员会职责：**
- 制定个人信息保护及数据安全管理工作的目标和年度规划
- 指导数据安全风险专项小组开展具体工作
- 发布公司个人信息保护及数据安全管理工作的社会责任报告
- 研究提出个人信息保护及数据安全相关重大决策建议

### 4.2 数据安全负责人

公司指定数据安全负责人，负责对数据处理活动以及采取的保护措施等进行监督。

### 4.3 数据安全风险专项小组

由合规部、信息安全部、公共事务部、市场与品牌沟通部指定相关人员组成，职责包括：
- 指定全公司个人信息保护及数据安全管理工作制度
- 制定实施数据安全、个人信息保护计划和安全事件应急预案
- 开展数据安全、个人信息风险监测，及时处置安全风险和事件
- 定期组织开展数据安全及个人信息保护宣传教育培训、风险评估、应急演练
- 受理、处置数据安全、个人信息投诉、举报
- 按照要求及时向网信部门和主管、监管部门报告数据安全情况

### 4.4 数据安全接口人

各部门设置数据安全接口人，负责对部门个人信息保护与数据安全管理工作进行监督。

## 5. 数据处理规范

### 5.1 收集规范

- 收集个人信息应满足法定条件（同意/合同必需/法定义务/紧急情况/公共利益/已公开/其他法定情形）
- 间接收集时应对数据提供方开展合规背景调查，确保来源合法
- 采用爬虫等自动化工具收集数据时应评估影响，不得干扰网络服务正常功能

### 5.2 存储规范

- 在中国境内运营中收集和产生的数据应当在境内存储
- 个人信息保存期限为实现处理目的所必要的最短时间
- 网络日志保存不少于6个月；金融客户身份资料自业务关系结束当年起不少于5年；劳动合同文本保存不少于3年

### 5.3 访问控制规范

- 遵循"业务需要"原则和"最小授权原则"
- 不同级别数据需按分类分级框架要求进行相应审批和操作
- 员工离岗离职、合作伙伴终止合作时及时终止访问权限

### 5.4 使用规范

- 应按照最小必要原则对数据的使用进行授权和验证
- 应定期对数据处理进行技术审计
- 应分离设置安全管理人员、数据操作人员、审计人员

### 5.5 委托处理与对外提供

- 委托处理/对外提供前应对合作方开展合规背景调查
- 对外提供个人信息需取得个人单独同意
- 重要数据的委托处理/对外提供还需开展重要数据安全影响评估

### 5.6 删除规范

- 处理目的已实现、产品服务停止提供、个人撤回同意等情形应删除个人信息
- 法律保存期限未届满或技术上难以实现的，应停止除存储和保护之外的处理

### 5.7 敏感个人信息保护规范

- 敏感个人信息包括：生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息
- 处理需具备特定的目的和充分的必要性
- 需取得个人单独同意并事前进行个人信息保护影响评估
- 不以人脸、指纹等生物特征作为APP登录等唯一的个人身份认证方式

## 6. 数据合规管理

- **制度规程：** 建立健全数据合规管理制度体系
- **安全措施：** 在网络安全等级保护制度基础上履行数据安全保护义务，使用合规密码产品，加强接口管理与漏洞检测
- **数据安全审计：** 信息安全部不定期对各业务系统开展审查与抽查，审计日志留存不低于3年
- **年度合规审计：** 自行或委托第三方专业机构进行年度合规审计
- **影响评估：** 处理敏感个人信息、自动化决策、对外提供等情形应事前进行个人信息保护影响评估
- **教育培训：** 每年开展一次全员数据安全培训；主要岗位人员每年不少于20小时培训
- **供应商管理：** 合作前开展背景调查，签署数据处理协议，定期监督

## 7. 渠道合规评估

各类渠道上线前均需开展合规评估：

| 渠道 | 关键要求 |
|------|----------|
| APP | 等保定级备案、工信部ICP备案、公安备案、隐私政策公示、双清单设置 |
| 网站 | 公安机关联网备案、隐私政策显著位置展示 |
| 小程序 | 各渠道同步更新规则、遵从小程序平台规范 |
| 公众号 | 收集页面展示隐私政策、跳转第三方链接提示用户 |
| SDK | 上线前安全检测、签订数据处理协议 |
| API | 参照对外提供/委托处理规范、加强接口安全审计 |

## 8. 数据主体权利响应

个人信息主体拥有以下权利：

- 知情权、决定权、查阅复制权、可携带权
- 更正补充权、删除权、解释说明权
- 逝者近亲属的权利

用户权利请求应在15个工作日内完成核查与处理。

## 9. 奖惩机制

- 各部门及员工应当履行相关法律法规和公司制度所赋予的各项职责
- 违反本政策的，按规定根据行为的严重情况予以相应惩戒
