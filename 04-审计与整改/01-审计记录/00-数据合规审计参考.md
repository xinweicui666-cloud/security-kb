# 数据合规审计参考

## 1. 概述

基于360数科（现奇富科技）2021年度数据合规审计实践和数据合规白皮书，梳理数据合规审计的重点关注领域和审计要点，为后续年度审计工作提供参考。

## 2. 审计依据

- 《网络安全法》《数据安全法》《个人信息保护法》
- GB/T 35273-2020《信息安全技术 个人信息安全规范》
- JR/T 0171-2020《个人金融信息保护技术规范》
- GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》
- 公司数据安全管理相关制度

## 3. 审计重点领域

### 3.1 制度体系建设

| 审计项 | 审计要点 |
|--------|----------|
| 制度完善性 | 是否建立了完整的数据安全管理制度体系 |
| 制度更新 | 制度是否及时根据法律法规变化更新 |
| 制度落地 | 制度是否落实到各业务部门和业务场景 |
| 配套规范 | 是否配套制定了操作规范和实施细则 |

### 3.2 数据分类分级

| 审计项 | 审计要点 |
|--------|----------|
| 分类分级覆盖 | 是否覆盖全量数据资产 |
| 分级准确性 | 数据定级是否准确合理 |
| 分级应用 | 分级结果是否在实际管控中应用 |
| 动态更新 | 是否定期更新分类分级结果 |

### 3.3 数据全生命周期管理

| 审计项 | 审计要点 |
|--------|----------|
| 数据收集 | 是否遵循最小必要原则，是否具有合法授权 |
| 数据存储 | 是否按级别加密存储，存储期限是否符合要求 |
| 数据使用 | 是否脱敏，是否超出授权范围，是否记录日志 |
| 数据传输 | 是否加密传输，跨境传输是否经过评估 |
| 数据提供 | 是否经审批，是否签署保密协议 |
| 数据删除 | 是否按期删除，删除是否彻底 |

### 3.4 个人信息保护

| 审计项 | 审计要点 |
|--------|----------|
| 隐私政策 | 内容是否完整准确，是否按期更新 |
| 授权同意 | 是否取得用户同意，敏感信息是否单独同意 |
| 权利响应 | 用户权利请求是否按时响应（15个工作日） |
| 影响评估 | 是否应评尽评，评估报告是否完整 |
| 投诉举报 | 投诉渠道是否畅通，处理是否及时 |

### 3.5 供应商管理

| 审计项 | 审计要点 |
|--------|----------|
| 准入评估 | 是否完成安全尽调和能力评估 |
| 合同约束 | 是否签署数据处理协议和安全条款 |
| 持续监督 | 是否定期评审，是否进行安全审计 |
| 退出管理 | 合作终止后数据是否妥善处理 |

### 3.6 安全培训

| 审计项 | 审计要点 |
|--------|----------|
| 培训覆盖率 | 是否覆盖全员，是否有记录 |
| 培训频次 | 是否满足每年至少一次要求 |
| 专业岗位培训 | 是否达到每年20小时 |
| 考核评估 | 是否进行培训考核 |

### 3.7 安全事件管理

| 审计项 | 审计要点 |
|--------|----------|
| 应急预案 | 是否有完整预案并定期更新 |
| 应急演练 | 是否每年至少一次演练 |
| 事件记录 | 事件是否完整记录和处理 |
| 事件报告 | 是否按规定时限上报监管 |

## 4. 审计方法

- 文档审查：审查制度文件、操作记录、审批记录
- 技术测试：系统配置检查、权限验证、日志审计
- 访谈调研：与相关负责人和操作人员访谈
- 抽样检查：对数据样本进行合规性验证

## 5. 审计频次

- 年度合规审计：每年至少一次，自行或委托第三方
- 专项审计：视业务需要和风险情况不定期开展
- 日常检查：信息安全部不定期对各业务系统开展抽查

## 6. 审计报告

审计报告应包含：
- 审计范围和依据
- 审计发现的问题
- 风险等级评估
- 整改建议
- 审计结论
